About Smart Route Optimizer

Ant Colony Optimization (ACO)

An algorithm inspired by social ants finding shortest foraging trails using pheromone deposition and evaporation. Start and destination are fixed, while intermediate stops are visited exactly once (Open TSP with Fixed Endpoints).

Data Modes

  • Demo Mode (Simulated Data): Generates physically realistic road costs via the Haversine formula, an urban circuity multiplier (1.35), and city speed models (35 km/h) without calling Google APIs or requiring credentials.
  • Live Mode (Google Data): Calls Google Routes API Compute Route Matrix v2 for live road costs and Compute Routes v2 for geometry.

Security

Google Maps Server API keys are strictly quarantined to the backend Python environment. The client receives only a website-restricted browser key.
