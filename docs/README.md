# Project Documentation Package

This directory contains the documentation package for the final-year engineering project: **Smart Shortest Path Finder Using Ant Colony Optimization (ACO) & Google Maps API**.

## Package Contents

1. [`project_report.md`](project_report.md):
   - **Academic Project Report**: Complete technical report containing the project abstract, problem statement, objectives, scope, methodology, mathematical modeling, empirical results, conclusions, and future enhancements.
2. [`presentation_slides.md`](presentation_slides.md):
   - **14-Slide Review Deck**: Comprehensive presentation outline formatted for final-year defense reviews, including slide titles, visual recommendations, bullet points, and speaker notes in simple English.
3. [`viva_questions.md`](viva_questions.md):
   - **25 Viva Voce Questions & Answers**: Thorough question-and-answer guide covering metaheuristic fundamentals, algorithmic mechanics, Google Routes API integration, security isolation, physical modeling, and testing.

All information in this package is derived directly from the verified source code and measured empirical test results.
